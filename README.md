So this is my project in which l am using C and created a information system for inventory in which different guns are present to facilitate the shopkeeper.
He will save the initial records just by one click.
By entering the code of any gun avaliable he can get information about it.
If a customer which color of a particular gun is present just by entering the color he can know about it.
For the ease of shop owner only by entering the name of area he can know the location of gun which are avaliable.
